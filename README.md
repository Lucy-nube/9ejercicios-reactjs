# 📚 9 Ejercicios ReactJS - Estructura Multipágina

¡Bienvenido al repositorio de mis ejercicios de React! Este proyecto fue desarrollado utilizando **React 19** y empaquetado con **Vite**.

 Cada ejercicio cuenta con su propio archivo HTML y su script de JavaScript independiente, demostrando que están programados de forma nativa en React sin manipulación directa del DOM.

---

## 🚀 Ejercicios Resueltos
1.  **Cambiador de Color de Fondo:** Manipulación de estilos mediante estados reactivos.
2.  **Contador de Clics:** Manejo básico de eventos y actualización de interfaces.
3.  **Lista Dinámica:** Creación, eliminación e interacción con arreglos en el estado.
4.  **Filtro de Búsqueda:** Filtrado de datos condicional en tiempo real.
5.  **Calculadora Sencilla:** Formulación y validación de datos para operaciones matemáticas básicas.
6.  **Temporizador:** Manejo de intervalos de tiempo con botones de pausa y reinicio.
7.  **Generador de Contraseñas:** Lógica de generación aleatoria de strings con longitud dinámica.
8.  **Contador de Palabras:** Manipulación de texto y contabilización en tiempo real.
9.  **Lista de Tareas con LocalStorage:** Persistencia de datos nativa en el navegador.

## 🛠️ Estructura del Proyecto
Para cumplir con los requisitos establecidos, el proyecto está segmentado de la siguiente manera:
*   **`index.html`**: Página de aterrizaje que sirve como índice para redirigir a cada ejercicio.
*   **`js_ejercicio_X.html`**: Estructuras HTML independientes para montar cada aplicación de React.
*   **`js_ejercicio_X.js`**: Lógica 100% React (utilizando `useState`, `useEffect` y `ReactDOM.createRoot`) en archivos separados.

*(Nota: Si GitHub indica que el repositorio es 100% HTML en sus estadísticas de lenguajes, se debe únicamente a que los archivos HTML pesan más en bytes. Todo el dinamismo del proyecto se ejecuta con scripts de JavaScript/React).*

## 📦 Cómo ejecutar el proyecto localmente

Si deseas descargar el proyecto y correrlo en tu máquina local, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Lucy-nube/9ejercicios-reactjs.git
   ```
2. **Entrar a la carpeta:**
   ```bash
   cd 9ejercicios-reactjs
   ```
3. **Instalar dependencias:**
   ```bash
   npm install
   ```
4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
5. Abre la dirección que te indique la terminal (normalmente `http://localhost:5173`).
